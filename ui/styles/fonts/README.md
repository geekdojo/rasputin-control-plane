# JetBrains Mono

The console and the sign-in pages bundle JetBrains Mono, so neither loads a font
from another host (geekdojo/geekdojo-brain#988). `../tokens.css` declares the
`@font-face` rules.

- **Source:** the official release
  [v2.304](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304),
  `JetBrainsMono-2.304.zip` (sha256
  `6f6376c6ed2960ea8a963cd7387ec9d76e3f629125bc33d1fdcd7eb7012f7bbf`), its
  `fonts/webfonts/` directory, unchanged.
- **Licence:** the SIL Open Font Licence 1.1, `OFL.txt`, copied from the same
  zip. Font data, not code.
- **Weights:** 400, 500 and 600, the three the console used from Google Fonts.
